资料管理 · 自定义版 2.3

双击“资料管理.exe”运行，无需安装。保持原有浅色侧栏和橙色主题。

# 每个文件的作用

1. 资料管理.exe
   程序本体，包含编译后的代码。双击打开界面，管理模块、分类和资料文件。
   日常使用需要保留；不需要打开源文件就能正常运行。

2. 模块设置.xml
   保存模块和分类的名称、对应文件夹，以及普通删除状态。
   程序下次打开时会读取它，恢复你的自定义设置。
   它不保存实际资料内容，请与 .exe 放在同一目录，日常使用需要保留。
   删除后不会直接删除资料文件，但会丢失自定义设置，并按实际目录重新识别模块。

3. Program.cs
   可阅读、可修改的 C# 源文件，对应当前 2.3 版程序。
   用于以后修改界面、功能或重新生成程序，运行时不需要它。
   修改源文件后需重新编译成 .exe 才会生效；只修改此文件不会改变正在使用的程序。
   删除它不影响当前程序运行，但建议保留，便于后续维护。

4. 使用说明.txt
   本说明文件，记录操作方式、每个文件的作用及备份注意事项。
   程序运行时不读取它，可用记事本打开查看。

# 资料文件夹的作用

5. 学习资料（文件夹，创建资料目录后出现）
   存放各模块、分类中的实际文件和子文件夹。
   这里才是导入的文档等资料内容，不能仅靠 .exe 或模块设置恢复。
   请保留其中需要的资料，备份时一起复制。

6. 移出资料（文件夹，有资料被彻底删除移出时出现）
   存放“彻底删除”模块时移出的原资料，按模块名称、时间和编号分开保存。
   文件并未销毁，可用资源管理器打开查看；它不属于程序的正常模块列表。
   其中有需要的文件时请保留，并一起备份。

# 使用方法

管理学期模块：首页右上角“管理模块” → 新增 / 重命名 / 删除。
管理分类模块：进入一个学期 → 右上角“管理分类” → 新增 / 重命名 / 删除。
新增学期会默认建立“专业、课程、其他”三个分类，可自由修改。
支持删除全部模块，再按需要添加。

恢复删除的模块：打开对应管理窗口，勾选“查看已删除模块”，选中后点击“恢复”。
未勾选时只显示正常模块，操作按钮为“删除”；勾选后只显示已删除模块，同一位置按钮变为“彻底删除”。
删除只从界面移除模块，不删除实际文件。删除学期时，其下的分类和文件也会保留。
重命名仅修改界面名称，原文件夹的实际路径保持不变。

彻底删除：在“管理模块”或“管理分类”中勾选“查看已删除模块”，选中模块，点击“彻底删除”。
确认后模块记录会移除，不能再通过“恢复”找回。
全部文件与子文件夹会整体移动至程序同级的“移出资料”文件夹。
每次移动生成“模块名称_时间_编号”独立目录，保留原层级，不覆盖其他资料。
操作成功后会显示保存位置，可选择立即打开。
移动或保存失败时不会完成模块删除；设置保存失败时会尝试将资料移回原处，并提示结果。
如果原资料文件夹已被手动移走或已不存在，仍可彻底删除模块记录，程序会提示“无文件需要移动”。
权限不足、原路径变成文件或其他访问异常不会被视为目录缺失，不会直接清理记录。
请同时备份“移出资料”，其中是你彻底删除模块时移出的原文件。

文件管理：进入分类后，可新建文件夹、导入文件、双击打开文件夹或文件。
导入会复制原文件，同名文件自动编号，不覆盖已有文件。

程序首次使用会读取旁边“学习资料”中的已有学期目录和分类目录，并保留原有文件。
“模块设置.xml”保存名称、分类及删除状态，运行时需要保留。
备份或换电脑时，请同时复制：
  资料管理.exe
  学习资料 文件夹
  模块设置.xml
  移出资料 文件夹（若有）
  使用说明.txt
  Program.cs（建议保留，便于以后修改程序）
日常运行不需要安装编译工具，也不需要打开 Program.cs。
不要删除模块设置文件，否则会重新按实际文件夹识别模块，已删除的模块可能重新出现。
请定期备份程序目录，以保留资料与模块设置。

本地 Windows 程序，需具备 .NET Framework 运行环境，不含云同步。
